Aula 09 - Funções exponenciais

Definição e gráficos da família y = aˣ; o número e; modelos de crescimento e decaimento

Descrição da aula

Uma função exponencial tem a forma f(x) = aˣ, com base a positiva e diferente de 1. A construção é cuidadosa: para expoente inteiro o significado é a multiplicação repetida; para expoente racional p/q recorre-se à raiz q-ésima; e para expoente irracional o valor é definido por aproximação pelos racionais. É essa última etapa que garante que a função esteja definida em todos os reais.

Os gráficos da família aˣ têm comportamento determinado pela base: para a > 1 a função é crescente e modela crescimento; para 0 < a < 1 é decrescente e modela decaimento. Em todos os casos o domínio é toda a reta, a imagem é o conjunto dos reais positivos, e o eixo x é assíntota horizontal — o gráfico se aproxima dele sem nunca tocá-lo.

Entre todas as bases possíveis, uma é privilegiada: o número e ≈ 2,71828. A razão só ficará clara no bloco 2, quando veremos que eˣ é a única função exponencial cuja derivada é igual a ela mesma. Essa propriedade é o motivo de e aparecer em praticamente todo modelo de crescimento populacional, decaimento radioativo e juros compostos contínuos.
