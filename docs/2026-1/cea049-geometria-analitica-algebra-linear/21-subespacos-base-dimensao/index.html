Aula 21 - Subespaços, base e dimensão

Base e dimensão de um espaço vetorial; espaço linha e espaço coluna

Descrição da aula

Uma base de um subespaço W é um conjunto B={V₁,…,Vₙ} que satisfaz duas condições simultaneamente: é linearmente independente e gera W. As duas condições são igualmente necessárias — um conjunto que só gera mas é L.D. tem vetores redundantes; um conjunto L.I. que não gera W é insuficiente.

O resultado central da aula é que todas as bases de um mesmo espaço vetorial têm o mesmo número de elementos — esse número é, por definição, a dimensão do espaço. ℝⁿ tem dimensão n, e sua base canônica {e₁,…,eₙ} é a referência mais simples possível. Uma vez fixada a dimensão de W, qualquer conjunto L.I. com esse número exato de vetores em W já é automaticamente uma base, sem precisar verificar separadamente se gera o espaço.

A aula ensina dois procedimentos práticos e complementares: verificar se um conjunto dado é base (checando L.I., contagem de elementos e geração) e construir uma base a partir do zero para um subespaço dado — encontrando primeiro um conjunto gerador e depois removendo vetores redundantes até sobrar um conjunto L.I. que ainda gera o espaço.
