Aula 05 - Sistemas de equações lineares: matrizes equivalentes

Sistemas homogêneos; matrizes equivalentes por linhas; classificação do sistema (SPD, SPI, SI)

Descrição da aula

Todo sistema linear se enquadra em uma de três categorias: possível determinado (SPD), quando tem exatamente uma solução; possível indeterminado (SPI), quando tem infinitas soluções; ou impossível (SI), quando não tem solução nenhuma. Reconhecer em qual categoria um sistema cai — normalmente pelo número de pivôs na forma escalonada em relação ao número de incógnitas — é tão importante quanto saber resolvê-lo.

Um caso particular merece destaque: um sistema é homogêneo quando todos os termos independentes são nulos (AX=0). Todo sistema homogêneo tem pelo menos a solução trivial (0,...,0), o que significa que homogêneo nunca é impossível — só pode ser SPD (só a trivial) ou SPI (infinitas soluções, incluindo a trivial).

A aula fecha formalizando a noção de equivalência: duas matrizes A e B são equivalentes por linhas, A∼B, se for possível transformar uma na outra por uma sequência finita de operações elementares. O teorema central da seção garante que sistemas cujas matrizes ampliadas são equivalentes têm exatamente as mesmas soluções — é esse teorema que justifica, em última instância, por que o método de Gauss-Jordan da aula anterior funciona: cada operação elementar produz um sistema equivalente ao original, mais simples de resolver.
