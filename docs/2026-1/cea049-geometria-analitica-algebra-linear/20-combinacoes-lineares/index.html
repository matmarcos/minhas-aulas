Aula 20 - Combinações lineares

Combinação linear; subespaço gerado; dependência e independência linear

Descrição da aula

Uma combinação linear de vetores V₁,V₂,…,Vₙ é qualquer vetor da forma a₁V₁+a₂V₂+⋯+aₙVₙ, para números reais a₁,…,aₙ. Dado um conjunto de vetores, o subespaço gerado por eles é o conjunto de todas as suas combinações lineares — por exemplo, os vetores da base canônica {e₁,…,eₙ} geram todo o ℝⁿ.

A pergunta natural é quando um conjunto de vetores é realmente necessário para gerar um subespaço, ou se algum deles é redundante — combinação linear dos demais. Essa pergunta leva à definição de dependência e independência linear: um conjunto {V₁,…,Vₙ} é linearmente independente (L.I.) quando a única solução da equação a₁V₁+⋯+aₙVₙ=0 é a solução trivial a₁=⋯=aₙ=0; caso existam soluções não triviais, o conjunto é linearmente dependente (L.D.).

Na prática, verificar se um conjunto é L.I. ou L.D. em ℝⁿ se reduz a um problema já dominado: monta-se a matriz com os vetores como colunas (ou linhas) e verifica-se se o sistema homogêneo correspondente tem só a solução trivial — o que, para uma matriz quadrada, equivale a ter determinante não nulo. É por isso que um conjunto com mais de n vetores em ℝⁿ é sempre L.D.: o sistema homogêneo associado necessariamente tem solução não trivial.
