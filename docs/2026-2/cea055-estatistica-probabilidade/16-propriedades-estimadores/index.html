Aula 16 - Propriedades dos estimadores

Estimador não viesado e viés; variância amostral S² (por que dividir por n − 1); estimador consistente; estimador mais eficiente; por que usaremos X̄, p̂ e S²

Tarefa

  • Um time de testes conta os bugs encontrados em cada versão de um app. Cada versão tem 0, 2 ou 4 bugs, cada valor com probabilidade 1/3. Assim, a média da população é μ = 2 bugs. O time sorteia 2 versões ao acaso. As 9 amostras possíveis são: 0 e 0; 0 e 2; 0 e 4; 2 e 0; 2 e 2; 2 e 4; 4 e 0; 4 e 2; 4 e 4.
  • (a) Em cada amostra, calcule a média X̄ e o menor valor. Depois, calcule a média das 9 estimativas de cada regra. Qual das duas regras é não viesada para μ? Qual é o viés da outra?
  • (b) Calcule a variância da população, σ².
  • (c) Em cada amostra, calcule σ̂² (soma dos quadrados dos desvios dividida por n = 2) e s² (dividida por n − 1 = 1). Calcule a média das 9 estimativas de cada fórmula. Qual delas é não viesada?
  • (d) Um colega propõe estimar μ usando só o número de bugs da primeira versão sorteada. Essa regra é não viesada? Ela melhora se o time sortear mais versões?
  • Tarefa opcional, sem entrega e sem nota — serve para você conferir se entendeu a leitura. Tente antes de abrir o gabarito.

(a) Média e menor valor

  • Média: médias das 9 amostras: 0, 1, 2, 1, 2, 3, 2, 3, 4; soma 18; média das 9: 18/9 = 2 = μ. X̄ é não viesado.
  • Menor valor: menores valores: 0, 0, 0, 0, 2, 2, 0, 2, 4; soma 10; média das 9: 10/9 ≈ 1,11. É viesado, com viés ≈ 1,11 − 2 = −0,89: em média, subestima μ.

(b) Variância da população

  • Conta: σ² = [(0 − 2)² + (2 − 2)² + (4 − 2)²]/3 = 8/3 ≈ 2,67.

(c) Dividir por n ou por n − 1

  • Uma amostra: 0 e 2: média 1, desvios −1 e 1, soma dos quadrados 2; então σ̂² = 2/2 = 1 e s² = 2/1 = 2.
  • Todas: amostras iguais: σ̂² = 0 e s² = 0; diferença 2 (quatro amostras): σ̂² = 1 e s² = 2; diferença 4 (duas amostras): σ̂² = 4 e s² = 8.
  • Médias: σ̂²: (4 × 1 + 2 × 4)/9 = 12/9 ≈ 1,33, só a metade de σ²; s²: (4 × 2 + 2 × 8)/9 = 24/9 ≈ 2,67 = σ². S² é não viesado; σ̂² subestima σ².
  • Erro comum: achar que, por ser a variância da Aula 2, σ̂² deveria acertar.

(d) Só a primeira versão

  • Viés: estimativas: 0, 0, 0, 2, 2, 2, 4, 4, 4; média 18/9 = 2 = μ. É não viesada.
  • Consistência: não melhora com mais versões, porque ignora todas as versões depois da primeira; a variância continua σ², qualquer que seja n. Não é consistente. Já a variância de X̄, σ²/n, diminui quando n cresce.
  • Leitura: acertar em média não basta.
