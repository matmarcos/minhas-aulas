Aula 18 - Intervalo de confiança para a média

Por que um intervalo informa mais que uma estimativa pontual; intervalo de confiança para μ com σ conhecido (normal) e com σ desconhecido (t de Student); o que significa "95% de confiança"; o que muda a amplitude; amostra grande

Pré-aula

Leitura recomendada

  • Bussab & Morettin, Estatística Básica, 9ª ed. — Capítulo 11, seção 11.6 (intervalo de confiança), até o intervalo para a média com σ conhecido.
  • Montgomery & Runger, Estatística Aplicada e Probabilidade para Engenheiros, 7ª ed. — Capítulo 8, introdução e seção 8.1.1.

As duas referências cobrem o mesmo conteúdo — basta ler uma. Atenção: o Bussab chama o nível de confiança de "coeficiente de confiança" (γ). Na aula usamos nível de confiança (1 − α).

Tarefa

  • Uma mineradora de Araxá mede o teor de nióbio do minério que extrai. O teor tem distribuição normal com desvio padrão conhecido σ = 0,5 ponto percentual. Numa amostra de n = 16 cargas, o teor médio foi x̄ = 2,4%.
  • Use a tabela normal P(0 ≤ Z ≤ z): ela dá a área entre 0 e z.
  • (a) Quanto vale o erro padrão σ/√n?
  • (b) Para 95% de confiança, sobram 5% nas duas pontas. Que área você procura no corpo da tabela, e qual é o z correspondente?
  • (c) Construa o intervalo x̄ ± z·σ/√n.
  • (d) Qual é a amplitude do intervalo? E se a amostra tivesse n = 64 cargas, com o mesmo x̄?
  • (e) Um colega disse: "há 95% de probabilidade de o teor médio μ estar no intervalo de (c)". Isso está certo?
  • Tarefa opcional, sem entrega e sem nota — serve para você conferir se entendeu a leitura. Tente antes de abrir o gabarito.
Ver gabarito comentado (tente antes de abrir)

(a) Erro padrão

  • Conta: σ/√n = 0,5/√16 = 0,5/4 = 0,125 ponto percentual.

(b) Valor de z

  • Tabela: 95% no meio deixam 2,5% em cada ponta. Procure 0,5 − 0,025 = 0,475 no corpo da tabela → z = 1,96.
  • Erro comum: procurar 0,95 ou 0,025 no corpo da tabela. Essa tabela começa em 0, não em −∞.

(c) Intervalo

  • Margem de erro: 1,96 × 0,125 = 0,245.
  • Intervalo: IC(μ; 95%) = [2,4 − 0,245 ; 2,4 + 0,245] = [2,155 ; 2,645]%.

(d) Amplitude

  • Conta: amplitude = 2 × 0,245 = 0,49 ponto percentual.
  • Com n = 64: σ/√n = 0,5/8 = 0,0625, e a amplitude cai para 0,245 — a metade. Quatro vezes mais cargas reduzem a amplitude à metade.

(e) Interpretação

  • Resposta: não. μ é um número fixo: o intervalo [2,155 ; 2,645] contém μ ou não contém.
  • O correto: se repetíssemos a amostragem muitas vezes, cerca de 95% dos intervalos construídos assim conteriam μ.
